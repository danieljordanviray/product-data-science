Active, New, and Returning Users (Over Time)

November 3, 2026

Active = New + Returning, in any time period, under any date filter. One flag — is_first_session, calculated in the dataset before a dashboard filter can touch it — keeps the split correct in SQL and Power BI, per day and cumulative.
